# Flight Seat Checker

This is a Python script simulating the process of booking seats for a flight.
Made for DSE 502 at the University of Maine, spring 2026.

## Features
* Seat Availability Tracking: View what seats are open or taken on a flight.
* Seat Recommendations: Suggests nearby alternative seats if your preferred choice is occupied.
* Flight Statistics: Calculates and displays basic statistics about the current flight capacity.
* Data Storage: Automatically reads from and updates an external `seats.txt` data file.

## Requirements
* Python 3.x

## How to Run
1. Make sure both `Flight Seat Checker.py` and `seats.txt` are saved in the same folder. 
2. Make sure path for `seats.txt` is appropriately assigned. 
3. Run the script from your terminal or IDE:
   ```bash
   python "Flight Seat Checker.py"
   ```
